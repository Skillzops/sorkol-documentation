# Understanding permissions

Use four independent action levels:

| Permission | Purpose |
| --- | --- |
| Manage | Administrative or advanced control of a module. |
| Read | View records and information. |
| Write | Create or update records. |
| Delete | Remove records where business rules permit it. |

Permissions can apply to modules including Sales, Customers, Inventory, Products, Warehouses, Quotes, Invoices, Reports, Audit Logs and Configuration. Enforcement applies through the application interface and backend API.
