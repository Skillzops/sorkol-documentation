---
title: Manage users
description: Add users and keep their access aligned with their responsibilities.
---

Create user records for staff who require workspace access, then assign appropriate roles. Review access when responsibilities change and remove it promptly when a person no longer requires it.


Prepare the [roles and permissions](/docs/users-and-access/roles) first, then assign each user to the appropriate role. Check access using the intended role before handing over operational work.

**Continue:** [Separation of duties](/docs/users-and-access/separation-of-duties).
