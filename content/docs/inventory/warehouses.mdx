Use warehouses to manage stock positions and fulfilment. Configure branch warehouse transfer controls and notifications to support reliable operational handoffs.

![Warehouse locations with stock totals and transfer status](/images/docs/live/warehouses-current.webp)

## Create a warehouse

1. Open **Inventory & Assets → Warehouses** and select **New Warehouse**.
2. Enter the warehouse name and location. Add an image and description if needed.
3. Select **Set as main warehouse** only for the main stock location.
4. Select the arrow button to save, then confirm the warehouse appears in the list.

Creating a warehouse does not add inventory. Record stock against the location before using it for fulfilment.
