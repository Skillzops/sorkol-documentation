# Platform overview

SORKOL brings customer management, quotes and sales, payments, invoices, inventory, device operations, commissions, tasks and reporting into a tenant workspace. Products and price books support both direct and instalment-based sales.

Use role-based access to give each user the functions needed for their work, then use audit and transaction history to review key activity.
