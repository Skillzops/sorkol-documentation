# Configure price books

Create draft price books with effective dates and product variants. Configure either One-Time pricing or PAYGO values for initial payment, recurring amount, instalment duration and payment mode. Activate the book to use it for future quotes and sales.

![Price book configuration](/images/docs/configuration/price-books.png)

Only one book is active for new sales at a time. Historical transaction values remain unchanged when you change future pricing.
