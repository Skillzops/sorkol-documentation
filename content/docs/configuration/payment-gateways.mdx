# Payment gateways

Open **Tenant Integrations** to configure an approved payment gateway in platform-managed or tenant-managed mode. Add the merchant ID, token, private key, gateway code and webhook details where applicable. Set the active/default gateway, processing fees and whether the fee is paid by the customer or tenant.

Supported processors include Flutterwave, Paystack and Ogaranya. Test and activate the provider before operational use. Sensitive credentials are encrypted at rest and masked in the interface.
