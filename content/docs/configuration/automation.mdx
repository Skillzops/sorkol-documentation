# Configure automation

Enable or disable the tenant AI layer, choose reminder/report/insight cadences and set a maximum daily execution allowance. Supported work includes invoice and unpaid-payment reminders, instalment renewal reminders, reports and customer insights.

Use the status information and manual-only option to retain operational oversight. AI-generated outputs support work but do not replace authorised human review or accountability.
