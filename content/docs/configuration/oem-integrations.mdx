# OEM integrations

Use **Tenant Integrations** to select an approved OEM platform and enter the application ID, API key and other required credentials. Test the connection before enabling operational vending.

Supported OEMs include GP IoT, Beebeejump, KPay, OpenPayGo, Sigenergy and custom OEM platforms. Additional OEMs are assessed against their API availability, documentation, security and compatibility.
