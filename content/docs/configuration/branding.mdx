# Configure branding

From **Settings**, select **Brand Customisation**. Enter approved hexadecimal colours for the core palette, then review sidebar and top-bar colours for light and dark modes. Select **Save Colors** and verify readability on key pages.

Use **Reset Defaults** to return to the standard SORKOL scheme. Limit this setting to authorised administrators and maintain accessible contrast between text, backgrounds and controls.
