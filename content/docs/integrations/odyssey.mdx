# Connect Odyssey

Open **Tenant Integrations** and locate the Odyssey panel. Copy the tenant Feed URL, generate or confirm the active access token, then share both securely with the authorised Odyssey integration team. Use **Send test request** to validate the connection.

![Odyssey integration controls](/images/docs/integrations/odyssey.png)

Rotate the token when credentials must be refreshed or are suspected to be exposed. Revoke it to stop authenticated access. SORKOL only displays limited token details after creation; each feed and token is isolated to its tenant.
