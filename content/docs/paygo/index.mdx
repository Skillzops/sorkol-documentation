# PAYGO

Use SORKOL to connect customer finance, repayments, device operations and portfolio monitoring in one workspace.

![PAYGO devices workspace](/images/docs/live/devices.redacted.png)

## Operating flow

Configure a PAYGO product, create a PAYGO sale, record the initial payment, create the instalment schedule, register and activate the device, receive repayments, then monitor the portfolio.
