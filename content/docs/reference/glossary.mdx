# Glossary

| Term | Meaning |
| --- | --- |
| Tenant | An organisation's isolated SORKOL workspace. |
| One-Time Sale | A direct sale paid in full without an instalment schedule. |
| PAYGO | A sale where an initial payment is followed by scheduled instalments. |
| Price book | A controlled commercial variant for a product. |
| OEM | A device or vending platform connected for PAYGO operations. |
| Master invoice | The primary invoice record for a sale, including PAYGO financing where configured. |
| Access token | A secret used to authenticate approved access to an integration, such as Odyssey. |
